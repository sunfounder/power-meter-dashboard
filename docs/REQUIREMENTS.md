# SunFounder 4CH 功率计 — 需求文档 (SDD)

> 版本：v1.0 ｜ 更新：2026-08-07
> 流程约定：**任何需求变更必须先更新本文档（版本+变更记录），再开始实现。**

---

## 1. 项目概述

4 通道功率计（ESP32-S3 / T-Display-S3），用于多通道电压/电流/功率测量与长时间数据记录。
配套 **网页仪表盘**（浏览器可访问）与 **Windows 桌面应用**（Electron 封装网页）。

- 固件：`firmware/`（PlatformIO，ESP32-S3）
- 网页：`web/`（单文件 index.html + vendor 资源）
- 桌面应用：`app/`（Electron，内嵌网页副本）
- 发布：`scripts/release.ps1` 一条龙（版本号 → 同步 → 打包 zip → GitHub Release）

## 2. 硬件平台

| 项 | 规格 |
|---|---|
| MCU | ESP32-S3（T-Display-S3，16MB Flash，PSRAM 可选） |
| 传感器 | INA226 ×4（I2C 0x40/0x41/0x44/0x45，电流/电压/功率） |
| 温度 | NTC ×4（经 ADS1115 ADC 分压）+ 环境温度（ADS1115 通道） |
| 显示 | 1.9" LCD（LVGL 9） |
| 按键 | A/B 物理按键 |
| 蜂鸣器 | 启动/停止提示音 |
| 网络 | AP + STA 双模式（2.4G） |

## 3. 功能需求

### 3.1 测量 (FR-MEAS)

- [x] **FR-MEAS-01**：4 通道独立测量 V / I / P（INA226，1s 采样，可配 0.1s~10s）
- [x] **FR-MEAS-02**：每通道 NTC 温度（ADS1115 采样，断线显示 `---`）
- [x] **FR-MEAS-03**：环境温度（校准偏移可配置，网页"当前温度校准"）
- [x] **FR-MEAS-04**：电流方向约定：**充电为正、供电为负**（ina226 取反）
- [x] **FR-MEAS-05**：传感器探测失败通道标记 disconnected（图表/数值隐藏）
- [x] **FR-MEAS-06**：温度单位切换（°C/°F，设备屏幕 + 网页联动）
- [x] **FR-MEAS-07**：蜂鸣器（启动双短音/停止长音提示，loop 上下文驱动防崩溃）

### 3.2 屏幕显示 (FR-DISP)

- [x] **FR-DISP-01**：顶栏：环境温度 + 时间 + WiFi 信号图标 + SSID + IP
- [x] **FR-DISP-02**：WiFi 图标按 RSSI 变色（绿≥-60 / 黄≥-75 / 橙≥-90 / 红<-90 / 灰=AP）
- [x] **FR-DISP-03**：4 通道卡片 V/A/W/C 实时数值（电流 2 位小数）
- [x] **FR-DISP-04**：时间显示使用 UTC+时区（time() 保持 UTC，显示层 +tz）
- [x] **FR-DISP-05**：屏幕旋转 0°/180°（设置项；90° 暂不支持）
- [ ] **FR-DISP-06**：录制状态指示（IDLE/录制/停止）

### 3.3 录制与存储 (FR-REC)

- [x] **FR-REC-01**：每通道独立开始/停止（网页/屏幕）
- [x] **FR-REC-02**：二进制 .dat 存储（24B/样本：uint32 时间戳 + float V/A/W/C/环境温度）
- [x] **FR-REC-03**：文件命名 `名字_chN_YYYYMMDD_HHMMSS.dat`（本地时间）
- [x] **FR-REC-04**：录制中可改名（生效到当前任务）
- [x] **FR-REC-05**：正常停止 → 文件改 `.done` 后缀（完成标记）
- [x] **FR-REC-06**：崩溃/断电恢复：开机检测未完成 .dat → **自动续录**（NTP 同步后；90s 兜底）
- [x] **FR-REC-07**：续录计时包含历史（最后样本-首样本时间戳 / 样本数×间隔）
- [x] **FR-REC-08**：自动停止条件（每通道独立）：
  - 总开关 + 电压低于阈值 + 电流低于阈值 + 最长时长 + 下降沿模式
  - 条件默认全开：0.5V / 0.01A / 8h / 下降沿
  - 10 样本连续满足才触发（防误停）
- [x] **FR-REC-09**：文件管理：列表/下载/删除/全选；**≤10 个文件自动清理最旧**
- [x] **FR-REC-10**：空间保障：录制前确保 8h 容量（按采样率计算，不足删最旧）
- [x] **FR-REC-11**：文件下载：WS 二进制 → 客户端转 CSV（带 BOM）
- [ ] **FR-REC-12**：**自动录制**（突发触发：电流/电压突变 → 自动开始并保留前 N 样本；掉低 → 自动停止）——规划中
- [ ] **FR-REC-13**：自动停止冗余样本数（当前固定 10）可配置——规划中

### 3.4 网络与时间 (FR-NET)

- [x] **FR-NET-01**：AP（SSID = 设备名-MAC尾缀）+ STA 双模式
- [x] **FR-NET-02**：STA 断线自动重连（事件回调非阻塞 + 退避）
- [x] **FR-NET-03**：NTP 同步（国内服务器 + IP 直连；3s 重试；time()=UTC）
- [x] **FR-NET-04**：WebSocket 为主通道（数据推送 1s + 命令请求/响应）
- [x] **FR-NET-05**：HTTP 保留（/api/* 供 Agent/AI 使用）
- [x] **FR-NET-06**：WiFi RSSI 实时上报（WS 广播 + HTTP status）
- [x] **FR-NET-07**：AsyncTCP 底层加固：事件队列 256、跨任务命令队列化（防 panic）

### 3.5 网页仪表盘 (FR-WEB)

- [x] **FR-WEB-01**：4 通道实时 V/A/W/C + 环境温度（1s）
- [x] **FR-WEB-02**：IDLE 实时预览曲线（X 轴真实时间，从当前时刻）
- [x] **FR-WEB-03**：历史数据：**分页获取（record_all，200/页）+ 转圈/进度 + 收完一次画**
- [x] **FR-WEB-04**：X 轴真实时间（设备时间戳）；tooltip HH:MM:SS
- [x] **FR-WEB-05**：Y 轴最小范围（V/A/W ≥0.5，温度 ≥1）——避免噪声放大
- [x] **FR-WEB-06**：V/A/W/C 曲线点击隐藏/显示（颜色联动）
- [x] **FR-WEB-07**：绝对值/带符号切换（每通道）
- [x] **FR-WEB-08**：隐藏未连接通道
- [x] **FR-WEB-09**：主题（深/浅色）
- [x] **FR-WEB-10**：录制控制（开始/停止/重置）、停止后显示下载/删除
- [x] **FR-WEB-11**：设置：设备名/AP 密码/STA/采样率/时区/温度单位/环境校准/旋转/自动停止条件/图表 X 轴默认范围
- [x] **FR-WEB-12**：文件管理器（列表/空间条/全选/下载/删除）
- [x] **FR-WEB-13**：API 文档页（右上角 ⓘ）
- [x] **FR-WEB-14**：调试面板按钮（DevTools）
- [x] **FR-WEB-15**：本地资源（echarts/font-awesome 内嵌，无外网依赖）
- [x] **FR-WEB-16**：WiFi 信号图标（顶栏，RSSI 变色）

### 3.6 桌面应用 (FR-APP)

- [x] **FR-APP-01**：Electron 内嵌网页（无菜单栏/滚动条，4 卡片等分铺满）
- [x] **FR-APP-02**：连接页（IP 输入，WS 直连判定）
- [x] **FR-APP-03**：自动更新：检查 GitHub Release → 下载进度 → 后台下载 → 重启应用/提示应用更新
- [x] **FR-APP-04**：更新成功后首次打开提示 changelog
- [x] **FR-APP-05**：导出日志（主进程保存）
- [x] **FR-APP-06**：版本显示（固件版本 + Dashboard 版本）

## 4. 非功能需求 (NFR)

- [x] **NFR-01 可靠性**：WS 大响应/推流不崩（命令队列化 + 背压 + abort 清理）
- [x] **NFR-02 时区**：时间存储 UTC，显示层加偏移（统一）
- [x] **NFR-03 兼容**：旧 .dat/.done 均可读（下载/分页/删除）
- [x] **NFR-04 安全**：webSecurity 开启 + CSP；命令 file 参数防路径穿越
- [ ] **NFR-05 日志**：设备 WebLog（/api/logs）保留；诊断日志清理（测试稳定后）
- [ ] **NFR-06 性能**：大数据量图表流畅（分页已验证；长录制 8h+ 待测）
