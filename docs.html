录制

方法路径请求体说明
POST/api/channel/{0-3}/record/startname=test开始录制（新建 .dat 文件）
POST/api/channel/{0-3}/record/stop—停止 + flush 缓冲区到 Flash
GET/api/channel/{0-3}/record/data—RAM 缓冲区数据（刷新恢复用）

文件管理

方法路径说明
GET/api/files列出 .dat 文件
GET/api/download?file=xxx.dat下载二进制数据（客户端转 CSV）
POST/api/delete?file=xxx.dat删除文件

.dat 二进制格式

每个采样 = 24 bytes (little-endian):
struct SampleBin {
  uint32_t timestamp;     // UNIX 时间秒
  float bus_voltage_V;
  float current_A;        // 安培
  float power_W;          // 瓦特
  float channel_temp_C;   // 摄氏度
  float ambient_temp_C;
};

// JS 解析: DataView
// getUint32(off,true), getFloat32(off+4,true), ...
