Files

MethodPathBodyNote
GET/api/files—List .dat files

POST/api/delete?file=xxx.dat—Delete file

.dat Binary Format

Each sample = 24 bytes (little-endian):

struct SampleBin {
  uint32_t timestamp;     // UNIX seconds
  float bus_voltage_V;
  float current_A;
  float power_W;
  float channel_temp_C;
  float ambient_temp_C;
};
// JS: DataView → getUint32(off,true), getFloat32(off+4,true), ...
